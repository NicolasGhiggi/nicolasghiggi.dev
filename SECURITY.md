# Security Policy

## Supported Versions

This is a personal website deployed continuously from the default branch.
Only the latest version on `main` (the one currently deployed) receives
security fixes.

| Version               | Supported          |
| --------------------- | ------------------ |
| `main` (latest)       | :white_check_mark: |
| Older commits / forks | :x:                |

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub issues,
discussions, or pull requests.**

Use one of the following private channels instead:

1. **GitHub private vulnerability reporting** (preferred): go to the
   [Security tab](../../security/advisories/new) of this repository and click
   *Report a vulnerability*.
2. **Email**: send the details to **YOUR_EMAIL_HERE**.

Please include as much of the following as you can:

* A description of the vulnerability and its potential impact
* Steps to reproduce, or a proof of concept
* Affected URL(s), file(s), or dependency
* Any suggested mitigation or fix

## What to Expect

* **Acknowledgement** within 72 hours of your report.
* **Initial assessment** and an indication of next steps within 7 days.
* Regular updates until the issue is resolved.
* Credit in the fix/advisory if you wish (let me know your preferred name or
  handle).

This is a personal, non-commercial project, so there is no bug bounty program.
I do appreciate responsible disclosure and will do my best to address valid
reports promptly.

## Scope

In scope: the source code in this repository and the website served at
`nicolasghiggi.dev`.

Out of scope: vulnerabilities in third-party services or platforms (hosting
provider, DNS, analytics, etc.), which should be reported to the respective
vendors, as well as social engineering, physical attacks, and denial-of-service
testing.
